## 注册账号

访问官网 [`https://api.zicc.cc`](https://api.zicc.cc)，点击登录或注册入口即可创建 Z-API 账号

可使用邮箱注册，支持`qq.com`、`gmail.com`、`163.com`，设置密码完成邮箱验证后即可使用。

### 创建 API Key

登录 Z-API 控制台，进入「API 密钥」页面，点击「创建密钥」。

![](/images/uploads/QQ20260812-232811.jpg)

**保持默认配置**

创建密钥时，如果您是新手，默认配置即可。

![](/images/uploads/QQ20260812-232835.jpg)

## **导入密钥到 Codex / VS Code**

推荐使用 CC Switch 工具进行一键配置，也可以手动设置环境变量。

快捷下载：[Windows 版本](https://github.com/farion1231/cc-switch/releases/download/v3.19.2/CC-Switch-v3.19.2-Windows.msi) / [macOS 版本](https://github.com/farion1231/cc-switch/releases/download/v3.19.2/CC-Switch-v3.19.2-macOS.dmg)。

CC Switch 是开源的一键配置工具，可以放心下载。想查看项目介绍，可以打开 [CC Switch 项目页](https://www.ccswitch.io/zh/)。下载好后，点击「一键配置」。

![](/images/uploads/QQ20260812-233619.jpg)

## **确定导入**

在弹窗里确认导入配置。

图示：CC Switch

![](/images/uploads/QQ20260812-233232.jpg)

## **确认启用**

确认启用 ccgo，然后重启 Codex / VS Code 即可。

图示：CC Switch

![](/images/uploads/QQ20260812-233805.jpg)
